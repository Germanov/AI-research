# Frontend Lessons Learned

## Purpose

This file captures repeated frontend-specific lessons that should be reused across repositories.

Examples include:
- design-system bypass
- responsive regressions
- inconsistent validation states
- weak empty/error state handling
- excessive component complexity
- missing visual verification

---

## How to Use This File

Add an entry when:
- the same UI or frontend process problem happens more than once
- a strong UI practice proves itself repeatedly
- a repeated review issue shows a missing rule
- a pattern should become shared team guidance
