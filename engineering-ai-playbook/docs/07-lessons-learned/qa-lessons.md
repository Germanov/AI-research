# QA Lessons Learned

## Purpose

This file captures repeated QA-related lessons that should improve verification, bug reporting, regression thinking, and review quality.

Examples include:
- vague bug reports
- missing regression notes
- incomplete verification evidence
- repeated non-happy-path misses
- weak PR review comments
- unclear expected behavior

---

## How to Use This File

Add an entry when:
- the same QA gap appears more than once
- a strong QA habit repeatedly proves valuable
- the team learns a clearer way to express risk or verification
- a recurring problem should influence checklists or workflows
