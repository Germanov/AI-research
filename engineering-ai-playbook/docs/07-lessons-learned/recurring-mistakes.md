# Recurring Mistakes

## Purpose

This file records repeated mistakes that are worth making visible to the team.

A mistake belongs here when it has happened more than once or when it reveals a pattern that should change how we work.

---

## How to Use This File

Record:
- what happened
- where it happened
- why it happened
- how it was fixed
- how to prevent it next time
- which guidance file should be updated if needed

This file is for shared learning, not blame.
